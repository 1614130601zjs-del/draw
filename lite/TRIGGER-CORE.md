# 触发核心阶段记录

## 已实现（纯逻辑，可单独测试）
- 解析完整 `image###提示词###` 标记，支持一条消息多个标记。
- 提供去掉标记后的可见文本。
- 要求调用方明确指出消息是否已完成，流式中间态不会被标记为 ready。
- 使用 chatId + messageId + markerIndex 生成稳定 triggerId。
- 触发任务幂等注册及 pending/running/succeeded/failed 状态迁移；失败后仅允许显式 retry。
